# TITAN FIT

**Treine. Registre. Evolua.**

PWA mobile-first do ecossistema TITAN dedicado à execução de musculação, cardio e acompanhamento de evolução.

## Estado atual

Versão `v0.1.0` em desenvolvimento. Esta etapa entrega apenas o shell do aplicativo: identidade, navegação, PWA e estados vazios. Não há perfil, login, treino fixo ou dados fictícios.

## Executar

```bash
npm install
npm run dev
```

## Validar

```bash
npm run lint
npm run typecheck
npm run test
npm run build
npm run validate
```

## Publicação

O aplicativo usa a base `/titan-fit/` para GitHub Pages.
