# Definition of Done

Uma entrega só é considerada concluída quando:

- Compila sem erros.
- Lint e typecheck passam.
- Testes passam.
- Validação do projeto passa.
- Funciona no caminho `/titan-fit/`.
- Não cria perfil, login ou dados fictícios.
- Não quebra o PWA ou caches de outros aplicativos.
- Documentação e changelog são atualizados.
