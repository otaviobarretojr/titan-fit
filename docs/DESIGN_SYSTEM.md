# Design System

## Identidade

- Dark premium.
- Azul elétrico para ações e destaques.
- Grafite para superfícies.
- Tipografia legível em telas pequenas.

## Regras

- Mobile-first.
- Área de toque mínima de 44 px.
- Navegação inferior fixa.
- Safe-area em dispositivos móveis.
- Uma ação principal por tela.
- Sem imagens externas ou emojis como ícones principais na versão final.
